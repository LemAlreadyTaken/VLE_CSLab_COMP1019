## Chức năng

- Baitap2: giải phương trình bậc nhất ax + b = 0, kiểm tra dữ liệu nhập bằng TryParse (có thêm cách dùng try...catch trong Baitap2_trycatch.cs.txt).

- Baitap4: xử lý chuỗi họ tên (ghép, tách, chuẩn hóa hoa thường và khoảng trắng).
