### Lab06 - ADO.NET (MDI, ListView, SQL Server)

## Thông tin sinh viên
- Họ tên: Nguyễn Đan Trường
- MSSV: 51.01.104.110
- Lớp: 51.01.CNTT.A

## Mô tả
Ứng dụng quản lý học sinh dạng MDI, kết nối SQL Server theo mô hình Connected của ADO.NET (SqlConnection, SqlCommand, SqlDataReader). Cơ sở dữ liệu tạo bằng `QuanLyHocSinh_ADO/DBHocSinh.sql`.

## Chức năng
- Form chính MDI: menu, toolbar, thanh trạng thái hiển thị giờ, sắp xếp cửa sổ bằng LayoutMdi (Cascade, Tile Vertical, Tile Horizontal, Arrange Icons).
- Đăng nhập (tài khoản bài thực hành: admin / 123); chưa đăng nhập thì khóa các chức năng.
- Quản lý Lớp: hiển thị bằng ListView (đổi kiểu hiển thị), thêm, sửa, xóa bằng câu lệnh có tham số.
- Bài tập về nhà - Hồ sơ Học sinh: hiển thị, thêm, sửa, xóa học sinh theo mô hình Connected.
